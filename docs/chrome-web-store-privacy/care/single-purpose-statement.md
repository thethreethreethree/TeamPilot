# C.A.R.E — Single Purpose Statement

_Paste into: Developer Dashboard → Privacy practices → "Single purpose"._

> C.A.R.E helps a signed-in subscriber understand and respond to the customer conversation shown on the web page
> they are currently viewing. When the user clicks the toolbar icon, a panel reads the on-page conversation and
> assists with it — summarizing the thread, diagnosing the underlying problem, coaching or drafting a reply, and
> (only when the user chooses) capturing the conversation into their own C.A.R.E workspace.

**One core function:** assist the customer conversation the user is looking at. Every feature (Summarize,
Dissect, Coach, Co-Pilot, and the optional Capture-to-workspace) serves that single purpose.
