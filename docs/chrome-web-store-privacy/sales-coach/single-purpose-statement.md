# Sales Coach — Single Purpose Statement

_Paste into: Developer Dashboard → Privacy practices → "Single purpose"._

> Sales Coach helps a signed-in subscriber understand and respond to the sales conversation shown on the web
> page they are currently viewing. When the user clicks the toolbar icon, a panel reads the on-page conversation
> and gives sales coaching on it — reading where the deal stands and drafting a suggested next message.

**One core function:** coach the sales conversation the user is looking at. Everything the extension does
(reading the room, drafting a suggested response, catching up on the thread) serves that single purpose.
