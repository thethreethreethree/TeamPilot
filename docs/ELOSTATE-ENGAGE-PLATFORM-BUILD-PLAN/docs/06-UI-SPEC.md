# 06 — UI spec

Engage is a Remote Sales tab, laid out like Gong's to-do list (#1014):
- **Today:** due and overdue steps, oldest first, each showing the person, deal, step and flow.
  - An email step opens the draft with "Open in email", "Copy" and "Mark sent".
  - A call step shows a tap-to-call number and the outcome picker.
  - A task step has "Done".
  - Every step can be skipped, and the enrolment paused or removed.
- **Flows:** a list, then an editor with steps (kind, delay, title, body with {first_name}, {company} and {deal} placeholders).
- **Analytics:** per flow and per rep.

On the deal panel: "Add to a flow" asks for the contact and the flow.
