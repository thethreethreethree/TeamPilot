# CLOSURE - Course editor autosave

## What is true now

The course editor keeps unsaved changes in this browser and offers them back when the editor opens again (with Start
over); saving or cancelling clears them; a draft of a course that has since been saved by someone else is dropped.

Un-named reliance: the draft is per browser, not per account — another device won't see it.
