# CLOSURE - Turn a Market topic into a tracker

## What is true now

On Remote Sales → Market, a manager can click "Track" on any topic: a keyword tracker is created with the topic's name
and every wording it was said in, listening on the customer's side, and recent calls are scanned so it starts with
hits. "Tracking ✓" links to Trackers; if the tracker can't be created (e.g. the name is taken) the reason shows next to
the topic.
