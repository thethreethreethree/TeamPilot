# CLOSURE - Link a call to its prospect, from any call view

## What is true now

Every finished phone or video call now asks its rep which prospect it was with — one of their open prospects, or a new
one named from the call — in the normal call view as well as in Macro Mode. Before, the option existed only in Macro
Mode and could only create a new prospect, which is why no call in production was linked. Linking is what fills a
prospect's last call date, its call summaries in Ask Coach, its sentiment and its calendar entries. A manager sees which
prospect a call belongs to; only the call's rep can link it.
