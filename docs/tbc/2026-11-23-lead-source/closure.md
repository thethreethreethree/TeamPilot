# CLOSURE - Lead source on prospects

## What is true now

A prospect can carry where it came from — "Webinar", "Referral", "Trade show" — set when it is added or later on its
card, with the sources already used suggested. Pipeline has a third view, Sources: for the pipeline in view (a rep's,
a report's or the team's), each source's prospects, open deals and value, won deals and value, lost deals, and win rate
on closed deals ("—" until one closes). Prospects with no source are counted in their own row. The Ask box also knows
each prospect's source. Every change of source is kept as history. The database change is applied.
